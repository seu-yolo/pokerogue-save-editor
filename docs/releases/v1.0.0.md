# 洛托姆口袋 v1.0.0 · 出发，训练家！

首个公开版本来了。洛托姆口袋是 PokéRogue 的非官方 Chrome 侧栏工具，用像素风的小口袋，为你的冒险补一点给养。

## 口袋里有什么？

- **局内补给**：自定金钱、队伍恢复、精灵球与道具，支持当前状态下撤销；下一次稀有野生遭遇可单次启用。
- **就决定是你了！**：永久解锁初始宝可梦，选择闪光、性格、蛋招式、特性和可选形态，保留原有收藏。
- **随机孵化，保留惊喜**：调整抽奖券，添加由游戏官方扭蛋逻辑生成的传说蛋，不提前展示内容。
- **备份与刷新**：保存前预览、本机操作记录、原生备份导出和重新连接按钮。

## 下载与安装

官网玩家下载 **`RogueSave-v1.0.0.zip`**。解压后，在 Chrome 的 `chrome://extensions/` 开启开发者模式，选择“加载已解压的扩展程序”，加载直接包含 `manifest.json` 的文件夹。刷新游戏页，再点击洛托姆口袋图标打开侧栏。

**`RogueSave-Offline-v1.0.0.zip`** 只连接 `http://127.0.0.1:8000`，用于另行准备的本机离线游戏，不包含游戏本体。

GitHub 自动提供的 `Source code` ZIP 不是扩展安装包。旧版用户请先结束进行中的保存，再更新原加载目录、重新加载扩展并刷新游戏；不要同时启用多个版本。

需要 Chrome 116+。适配的游戏版本为 **1.12.0.10 / 1.12.0.11**；游戏更新后的未知版本保持只读。

## 本次修复与验证

修复游戏因账号会话过期重新载入数据后，修改器失败回滚覆盖新账号状态和缓存的问题。现有写入锁、备份和核对保留，正常网络失败仍恢复本次修改前的本地状态。

177 项自动化测试通过。独立离线 Guest 实测了局内保存与撤销，以及金钱、道具、红闪火焰鸟配置、券和传说蛋重载后的持久化。实测直接使用页面适配器，完整 Chrome 扩展 IPC 由自动化回归覆盖；原生文件导入恢复回环尚未验证。详细范围见 [首发审查](https://github.com/seu-yolo/rotom-pocket/blob/v1.0.0/docs/REVIEW-2026-10-06.md)。
