# 首发准备

本仓库用于洛托姆口袋的私有开发和首次发布准备。当前开发版本为 `0.4.4`，首个公开版本计划使用 `1.0.0`，尚未创建公开发行版。原开发工作区和 Chrome 已加载的扩展目录保持不变。

## 仓库整理

源码可以独立克隆、检查和测试。打包默认输出到仓库自己的 `dist/`，不再依赖原工作区层级；官网版与离线版分别生成，第三方素材说明随安装包保留。合成数据只放在 `tests/fixtures/`。

真实存档、账号导出、游戏本体、依赖和构建产物不提交到 Git。文档中的测试范围继续区分源码核对、模拟测试和实际游戏验证。

2026-10-05：25 个 JavaScript 文件语法检查通过，172 项自动化测试通过，官网版与离线版完成本地打包。本次仓库整理没有连接或修改实际游戏存档。

## 公开发布前待办

- 修复传说蛋成功响应缺少 `adapterVersion` 的问题。目前后台可能在账号已保存后将结果标为待确认；不要以绕过保护的方式处理。
- 用可恢复的离线测试存档完成保存、重新加载和撤销的常用功能验证。账号收藏、券和蛋的实际持久化验证另行记录。
- 确定自有代码许可证，复核代码来源，并把相应 LICENSE 随安装包分发。素材和字体保留各自许可，不能用自有代码许可统一覆盖。
- 首发时统一更新清单、package、核心／适配器常量、界面和文档中的版本号，补齐更新记录和安装说明。

许可证确定和上述收尾完成之前，仓库保持私有，不按稳定版宣传。

## 后续维护

日常修改先运行 `npm run check` 和 `npm test`，再提交代码。需要交付安装包时，运行 `npm run pack` 与 `npm run pack:offline`，在对应测试环境验证后发布。

源码与文档提交到 Git；安装 ZIP 放在 GitHub Releases，不提交 `dist/`。每次发布用独立版本标签定位源码，不覆盖旧版安装包。

游戏版本与扩展版本分别记录。当前只声明支持 `1.12.0.10` 和 `1.12.0.11`；未知版本保持只读。游戏更新后核对运行时结构、保存接口和具体功能，补测试，再扩大支持范围。
