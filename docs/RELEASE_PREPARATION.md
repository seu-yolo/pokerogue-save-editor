# 首发准备

首发版本统一为 `1.0.0`，安装包在 [GitHub Releases](https://github.com/seu-yolo/pokerogue-rotom-pocket/releases/tag/v1.0.0) 提供。原开发工作区和 Chrome 已加载的扩展目录保持不变；本地安装产物在独立仓库的 `dist/`。

## 仓库整理

源码可以独立克隆、检查和测试。打包默认输出到仓库自己的 `dist/`，不再依赖原工作区层级；官网版与离线版分别生成，第三方素材说明随安装包保留。合成数据只放在 `tests/fixtures/`。

真实存档、账号导出、游戏本体、依赖和构建产物不提交到 Git。文档中的测试范围继续区分源码核对、模拟测试和实际游戏验证。

2026-10-05：25 个 JavaScript 文件语法检查通过，173 项自动化测试通过。传说蛋响应已补齐版本字段和账号 JSON 快照。四页界面用合成数据检查，没有连接或修改实际游戏存档。

## 2026-10-06 首发复核

账号重新初始化后的回滚覆盖问题已修复，177 项自动化测试通过；MIT LICENSE 已随官网／离线安装包分发。独立离线 Guest 验证了常用保存、撤销与重载持久化，测试边界和未验证项见 [首发审查](REVIEW-2026-10-06.md)。

源码使用 `v1.0.0` 标签定位，Release 分别提供官网与离线 ZIP。源码 ZIP 不是扩展安装包。未操作用户的官网存档，也未替换本机已加载的扩展。

以上为首发准备时的待办；当前结果以本页复核、首发审查和对应 Release 为准。

## 后续维护

日常修改先运行 `npm run check` 和 `npm test`，再提交代码。需要交付安装包时，运行 `npm run pack` 与 `npm run pack:offline`，在对应测试环境验证后发布。

源码与文档提交到 Git；安装 ZIP 放在 GitHub Releases，不提交 `dist/`。每次发布用独立版本标签定位源码，不覆盖旧版安装包。

游戏版本与扩展版本分别记录。当前只声明支持 `1.12.0.10` 和 `1.12.0.11`；未知版本保持只读。游戏更新后核对运行时结构、保存接口和具体功能，补测试，再扩大支持范围。
