# 使用说明

安装从 [首页](../README.md#安装) 开始。以下补充功能范围，以及出错时怎样保留记录、核对状态。

## 功能范围

| 功能 | 可调整内容 |
| --- | --- |
| 金钱 | 设置最终总金额，`0–9,007,199,254,740,991`（安全整数上限）；支持无尽模式大金额 |
| 队伍恢复 | HP 全满、清除异常、PP 全满 |
| 精灵球 | 五种常用球各 `0–99` |
| 队伍进阶 | 亲密度、宝可病毒、暂停进化、六项 IV 设为 31 |
| 道具 | 新增受支持的永久／持有道具，修改部分现有道具层数；不支持任意生成器道具 |
| 对局名称 | `1–40` 个字符 |
| 收藏 | 解锁合法初始宝可梦及其可用普通／黄蓝红闪、初始形态、性格、蛋招式、普通与隐藏特性 |
| 抽奖券 | 四种券各 `0–9,999`，设置目标总数量，不会自动抽蛋或消耗券 |
| 随机传说蛋 | 每次 `1–10` 枚，可选传说 UP／蛋招式 UP／闪光 UP；总蛋数不超过 99，仍需 100 波孵化 |
| 一次性稀有遭遇 | 下一次野生战从实际地形的最高非空官方稀有池随机选择；可取消等待 |

功能按上表分为局内补给和永久收藏。想获得指定伙伴，用“收藏”；想保留孵化惊喜，用随机蛋。

<details>
<summary>尚未提供的修改项</summary>

波数、种子、当前队伍等级、经验、招式、闪光、融合或敌方数据暂不提供直接修改。收藏糖果、被动、成就、通关次数及账号身份也不在修改范围内。

</details>

### 添加道具

在“局内”展开“添加道具”，点“查看道具”，选道具、数量和持有者，点击“加入本次修改”，最后预览并保存。

上限从当前游戏的道具对象读取，不统一写死为 99；保存时还会重新检查。例如闪光护符已有 2 层、上限为 4，加入 1 层后仅剩 1 层可添加。持有道具按所选宝可梦分别计算，修改现有层数也会更新额度。

### 收藏与下一次开局

按名字或编号搜索并选择宝可梦。展开性格、蛋招式或特性，勾选要补充的内容，再“查看解锁内容”并保存。性格可多选；不支持的闪光变体和形态不可选。

已有解锁只保留和补充。它不会替换当前队伍；保存的内容在下次初始宝可梦选择页面使用。

### 一次性稀有遭遇

点击“等待下一次极稀有遭遇”，工具等到下一次野生战，在生成当刻读取实际地形，按 `ULTRA_RARE → SUPER_RARE → RARE` 选择最高非空官方池；Boss 层使用对应 Boss 池最高档。训练家层不消耗等待，双打仅影响第一只。

物种仍从该池随机抽取，不预览结果。等级、形态、性别、特性、招式、IV 和闪光继续由游戏生成。刷新游戏页会取消等待。

## 保存失败或结果待确认

看到保存异常时，先暂停修改，按下面的提示核对。`1.0.0` 已修复传说蛋成功响应缺少版本字段、被误判为“待确认”的问题；旧的待确认记录仍需按提示处理。

| 提示 | 你可以怎么做 |
| --- | --- |
| 状态已变化／账号数据已变化 | 停止推进游戏，点顶部刷新，重新预览 |
| 当前阶段不允许写入 | 等回到选择招式界面再操作 |
| 游戏版本不兼容 | 等待适配；期间可查看和导出备份 |
| 实际存档变化与白名单不一致 | 保留错误信息和记录，刷新核对；若仍不一致，重新载入游戏后再核对 |
| 实时会话与缓存不一致 | 重新载入游戏，进入同一存档的稳定指令界面，再刷新口袋 |
| 结果待确认／旧页面可能仍在运行 | 不重复保存；必要时关闭原游戏标签页，新开同一账号和存档，核对后刷新口袋 |

`0.4.3` 已修复 HP 道具的正常联动、回滚和撤销；旧的待确认记录不会自动删除。更新扩展后若仍出现 `session.party[...].hp` 差异，保留 JSON／原生备份并反馈，不要卸载扩展或删除记录来绕过。

账号保存以游戏官方 `saveSystem()` 返回值和当前浏览器实时快照检查为依据，不是独立查询服务器。保存失败或通信中断时，本地恢复成功也不代表服务器没有写入。因此应重新进入账号，核对收藏、券和蛋，不要只看工具提示就断定成功或失败。

### 三种刷新不是一回事

- 口袋顶部“↻ 刷新”：重新连接并核对状态，不刷新游戏，也不替换扩展代码。
- 刷新／重新打开游戏页：重新载入游戏状态，取消尚未触发的遭遇等待。
- 扩展管理页“重新加载”：在更新安装文件后加载新代码；不要在保存进行中使用。

## 备份与撤销

每次写入前，工具会自动保存本地事务备份；写入后回读当前浏览器的游戏缓存与实时状态。记录保存在扩展本地存储，不上传。不要卸载扩展或清空数据，以免丢失备份和待确认记录。

- **原生 `.prsv`**：在“备份”下载游戏自身格式的对局／账号文件。修改前下载的才是修改前备份；事后导出的文件不能替代它。兼容离线版可导入，官网正式版目前没有对应菜单导入入口。
- **事务 JSON**：保存修改前后信息，用于排查，不是游戏可直接导入的文件。已有完整性校验只覆盖对局快照，不覆盖账号快照。分享前检查并删除个人数据。
- **局内撤销**：仅在当前状态与该次修改后的状态一致时可撤销，包括新增道具。推进游戏后可能不再满足条件。
- **账号资源**：收藏、券和蛋暂不提供一键撤销。兼容离线版可以导入修改前的原生账号 `.prsv`，但这会覆盖相应存档，不只取消单项修改。

离线版与官网账号分开，游戏本体需另行准备。离线扩展仅操作 `http://127.0.0.1:8000/`；换端口或改为 `localhost` 会进入不同存储空间。具体见 [离线测试说明](OFFLINE_TESTING.md)。
